# Method 1 - 스테이크홀더 맵 (lo-fi 초안)

프로젝트: travel-agent-p · 작성일: 2026-09-16 · 상태: 러프 초안 (다듬지 않음)

## Primary

| 대상                | 역할                        | 영향력                              |
|---------------------|-----------------------------|-------------------------------------|
| 직장인 단기 여행자  | 일 사용자 · 의사결정자      | 높음 — 쓸지 말지를 혼자 결정        |
| 동행자              | 일정 합의 주체              | 높음 — 합의 안 되면 일정이 무효화됨 |

## Secondary

| 대상                  | 역할                | 영향력                                 |
|-----------------------|---------------------|----------------------------------------|
| 여행 블로거           | 정보 공급           | 간접 — 콘텐츠 품질이 결과 품질을 좌우  |
| 숙박/교통 API 제공자  | 데이터 의존 대상    | 중간 — 데이터 없으면 시간표가 안 서   |

## Hidden

| 대상                  | 역할                         | 영향력                                   |
|-----------------------|------------------------------|------------------------------------------|
| 개인정보 처리 담당    | 위치·일정 데이터 거버넌스    | 차단 가능 — 저장 범위에 제동            |
| API 이용약관          | 크롤링 금지 조항             | 차단 가능 — 정보 수집 경로를 제한       |
