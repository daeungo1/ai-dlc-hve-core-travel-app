# Method 1 - 가정 로그 (lo-fi 초안)

프로젝트: travel-agent-p · 작성일: 2026-09-16 · 상태: 러프 초안 (분석·우선순위 없음)

## 알려진 사실

- 팀 1인
- 기간 2일
- Azure OpenAI 사용 가능
- 배포 범위는 로컬 실행까지
